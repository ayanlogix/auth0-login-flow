# 🔐 Auth0 Login Flow

A secure authentication demo built with Auth0 for MLH Global Hack Week GenAI 2025.

## Features
- ✅ OAuth 2.0 / OpenID Connect authentication
- 🛡️ Auth0 Universal Login Page  
- 🔑 JWT Token Authentication (RS256)
- 🌐 Social Login Support
- 🎨 Beautiful glassmorphism UI with dark theme

## Setup
1. Create an Auth0 account at https://auth0.com
2. Create a new Single Page Application
3. Update domain and clientId in index.html
4. Add your app URL to Auth0 Allowed Callback/Logout URLs
5. Open index.html in browser

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Auth0 SPA SDK v2.0
- Google Fonts (Inter)

## Live Demo
Open index.html in any browser to see the login UI.
